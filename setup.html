Generatore locale di config.json

Apri questo file solo sul tuo computer. Il PAT e la API key AI vengono usati in memoria per cifrare i payload e non vengono salvati né inviati da questo helper.

Owner GitHub = username GitHub o organizzazione, ad esempio walter.
Repository = solo il nome del repository, ad esempio ricettario. Non inserire password, URL o .git. Lascia i campi vuoti se vuoi usare il rilevamento automatico da GitHub Pages.

Importazione ricette da foto/PDF (opzionale)

La chiave viene cifrata con la password Admin. Il modello viene chiamato direttamente dal browser solo durante una sessione Admin.

Modello: gemini-flash-latest. L’app usa automaticamente l’ultima versione Flash disponibile.

Password di sola lettura

Le password non vengono inserite nel JSON: vengono salvati solo hash PBKDF2 con salt casuale.
